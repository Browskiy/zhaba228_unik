## 2026-11-17: Індивідуальні завдання на 18.11 і 19.11

### Застосунок DoctorApp (електронна реєстратура)
ASP.NET Core MVC (.NET 8) + PostgreSQL через Entity Framework Core (Npgsql).

**Що вміє:**
- реєстрація та вхід, ролі: пацієнт, реєстратор, лікар, адміністратор;
- лікарі: пошук за спеціальністю й прізвищем, додавання, зміна, видалення (реєстратор/адмін);
- запис на прийом по вільному часу, перенесення, скасування; захист від подвійного запису (перевірка + унікальний індекс у БД);
- журнал записів для реєстратора, позначки «Проведён» / «Неявка»; лікар бачить своїх пацієнтів на дату;
- сповіщення (запис, перенесення, скасування, неявка, нагадування за 24 год);
- звіти за період: по лікарях, спеціальностях, частка неявок, завантаження по днях, вивантаження CSV.

**Як запустити:**
1. Встановити PostgreSQL (https://www.postgresql.org/download/). Під час встановлення задати пароль користувача `postgres`.
2. У `DoctorApp/appsettings.json` у рядку `DefaultConnection` вписати свій пароль замість `Password=postgres`.
3. Відкрити `DoctorApp/DoctorApp.slnx` у Visual Studio і натиснути ▶ (або `dotnet run` у папці `DoctorApp`). База `doctorapp`, таблиці й тестові дані створяться самі.

**Тестові входи:**

| Роль | Логін | Пароль |
|---|---|---|
| Адміністратор | `admin` | `admin123` |
| Реєстратор | `registrar` | `registrar123` |
| Лікар | `ivanova` | `doctor123` |
| Пацієнт | `petrov` | `patient123` |

SQL-скрипт створення таблиць лежить у `DoctorApp/Database/schema.sql`.

**Перевірено:** 20 сценаріїв автоматично в браузері на реальному PostgreSQL 16 (реєстрація, вхід, запис, подвійний запис, перенесення, скасування, ролі, звіти, CSV, лікарі). Усі пройшли.
