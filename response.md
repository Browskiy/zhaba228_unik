### Як запустити
Відкрий `Labs.sln` у Visual Studio, у Solution Explorer клікни правою кнопкою по потрібному проекту → **Set as Startup Project** → ▶.
Або з консолі:
```bash
dotnet run --project Task16_Strings
dotnet run --project Task17_Rational
```

### 16.11: слова з повторюваними буквами (варіант 6)
- Логіка в `WordFilter.cs`, форма в `MainForm.cs`.
- Методи string: `Split`, `Trim`, `ToLower`, `Replace`, `Concat`, `Length`.
- Кнопки «Выполнить», «Очистить», «Выход». Якщо слів < 5, з'являється повідомлення про некоректне введення. Після результату програма питає «Повторить?».
- Приклад: «Мама купила молоко, а папа банан и кокос. Ананас тоже был вкусным.» → `молоко Ананас`.

### 17.11: раціональні числа (структура)
- `Rational.cs`: `struct Rational { Numerator; Denominator; }` + `RationalMath.FindMax(Rational[])`.
- Числа додаються кнопкою «Добавить» (новий об'єкт структури в пам'яті), кнопка «Найти максимум» знаходить найбільше.
- Порівняння точне, через перехресне множення (a·d > c·b), без `double`.
- Повідомлення про некоректне введення: не число, знаменник 0, порожній масив. Також є «Очистить», «Выход» і «Повторить?».
